Seletor dos três modos de jogo, em pílula.

- Trilho `panel` com borda `line`; cada aba no estilo `aba`, texto `muted`.
- Aba ativa: fundo `ink`, texto `bg`, marcada com `aria-pressed="true"`.
- No celular (até 760px) o seletor ocupa a largura toda e as abas dividem o espaço por igual.
- Sempre três abas, nesta ordem: Diário, Relâmpago, Livre.
