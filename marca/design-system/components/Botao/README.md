Botão em pílula para as ações do jogo. Use `.cm-btn` para ações secundárias, `.cm-btn--primary` para a única ação principal da tela (Enviar, Jogar de novo) e `.cm-btn--round` para ações de um só ícone dentro da fileira de controles.

- Fundo `panel`, borda `line`, raio `radius-pill`, rótulo no estilo `botao`.
- Primário: fundo `ink`, texto `bg`. Uma vez por tela.
- Desabilitado: opacidade .45, sem cursor de mão.
- Foco: anel `plum` de 3px com 2px de afastamento.
- Rótulos são verbos curtos no infinitivo ou imperativo: "Enviar", "Apagar", "Compartilhar".
- Agrupe em `.cm-controls` (espaço `space-10`, quebra de linha centralizada).
- O botão redondo precisa de `aria-label` ("Embaralhar letras").
