# Segurança

A Colmeia de Palavras é um jogo estático: não tem servidor, contas nem banco de dados. O progresso fica só no navegador de quem joga, e a medição de uso (Umami, sem cookies) não recebe palavras digitadas nem dados pessoais.

## Como avisar de um problema

Se encontrar uma falha de segurança no jogo, no site ou neste repositório, **não abra uma issue pública**. Use o aviso privado do GitHub: aba **Security** → **Report a vulnerability** (ou escreva para o dono do repositório pelo perfil @yago-ananias).

Conte o que encontrou, como reproduzir e o que alguém poderia fazer com isso. A resposta vem assim que possível, e a correção é publicada no site depois que os testes passam.
